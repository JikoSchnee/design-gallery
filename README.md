# Design Gallery

A collection of static web designs by JikoSchnee, published with GitHub Pages.

**Gallery:** https://jikoschnee.github.io/design-gallery/

## Designs

- [Nature](https://jikoschnee.github.io/design-gallery/nature/) — art storefront with a catalog and product page. Cart and subscription interactions are local demos.
- [Shapes](https://jikoschnee.github.io/design-gallery/shapes/) — Hella Goods pantry storefront with goods catalog, product page, recipes, restaurant menu, and local demo cart.

## Add a design

1. Add its self-contained static files in a new folder at the repository root.
2. Add a thumbnail image or reuse an image from that folder.
3. Add a card in the root `index.html` linking to the new folder and update the collection count.

Use relative paths inside each design so it works both locally and under the `/design-gallery/` GitHub Pages path.
